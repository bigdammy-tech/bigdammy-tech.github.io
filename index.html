Ejire Cosmetics

Java Spring Boot PostgreSQL HTML/CSS/JS Paystack Render Netlify

Overview

A full e-commerce platform built for Ejire Cosmetics, a beauty products reseller business. Backend built with Java Spring Boot and PostgreSQL, deployed live on Render, with a responsive HTML/CSS/JS storefront deployed on Netlify — covering a 200+ product catalogue, cart, checkout, and payments.

Key Features

  • 200+ product catalogue across body creams, lotions, perfumes and skincare
  • Cart drawer with live stock validation and autocomplete search
  • Paystack payment integration with a secure async/callback flow
  • Geolocation-based delivery banner with persistent local storage
  • Cold-start retry logic and lazy image loading for a smooth mobile experience
  • Production database migrated from MySQL to PostgreSQL using Spring Boot profiles

Tech Stack

  • Java Spring Boot backend with Spring Data JPA
  • PostgreSQL in production, MySQL in development
  • HTML5, CSS3 and vanilla JavaScript frontend
  • Paystack for payments
  • Backend deployed on Render, frontend deployed on Netlify
